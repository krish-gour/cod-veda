# Power BI Dashboard task files

- `data/social_media_sentiment_raw.csv` — supplied data to import into Power BI.
- `Power_Query_Cleaning.m` — query for removing exported index columns, trimming text, and assigning types. Update the file path before using it.
- `Measures.dax` — measures for the visuals.
- `Dashboard_Build_and_Publish_Guide.md` — steps to create, interact with, and publish the report.

The ZIP does not contain a completed `.pbix`; the Power BI Desktop and Service steps must be performed in your Microsoft environment.
