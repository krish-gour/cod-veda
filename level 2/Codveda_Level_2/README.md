# Codveda Data Analytics — Level 2

This ZIP contains the three Level 2 task notebooks and the relevant supplied datasets. Open each notebook in Jupyter from its task folder so the relative `data/` paths work. Run cells from top to bottom.

## Tasks included
1. **Regression Analysis** — simple linear regression using `RM` to predict `MEDV`; train/test split; coefficient interpretation; R-squared and MSE.
2. **Time Series Analysis** — AAPL weekly closing price; time-series plot; statsmodels decomposition; 4-week moving average. The stock dataset is filtered to AAPL only.
3. **K-Means Clustering** — standardized Iris measurements; elbow method; 2D cluster visualization.

## Environment
Python 3 with pandas, numpy, matplotlib, seaborn, scikit-learn, and statsmodels.

Install missing packages in the active Anaconda environment with:

```bash
conda install pandas numpy matplotlib seaborn scikit-learn statsmodels
```

The notebooks were executed and checked against the included data files.
